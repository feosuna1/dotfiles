# Tool Usage

- Use Skills when tasks match their purpose.
- To read files use `Read` tool instead of `cat`, `head`, `tail`, or `sed`.
- To edit files, use `Edit` tool instead of `sed` or `awk`.
- To search through files, use `Search` tool instead of `grep` or `rg`.
- To find files, use `Glob` tool instead of `ls` or `find`.
- For version control, make sure you understand if the repo uses Git or Jujutsu and use the appropriate commands.
